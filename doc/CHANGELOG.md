# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Initial release of video Flux
- video upload API with multiple format support
- video download and resize API
- Admin UI for video management
- GraphicsMagick-based video processing
- Support for multiple storage backends (MinIO, AWS S3, Alibaba Cloud OSS)
- JWT authentication for API security
- Docker support for easy deployment
- Modular architecture with separate modules for upload, download, and admin UI

## [0.0.1-SNAPSHOT] - 2026-05-30

### Added
- Project initialization with Spring Boot 3.3
- Basic video upload functionality
- MinIO storage integration
- AWS S3 storage integration
- Alibaba Cloud OSS storage integration
- Admin UI with Thymeleaf
- JWT authentication
- H2 database support
- Dockerfile for containerization

- **Changed**: Changes in existing functionality
- **Deprecated**: Soon-to-be removed features
- **Removed**: Removed features
- **Fixed**: Bug fixes
- **Security**: Security vulnerability fixes
